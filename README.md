## 💡 About the Project

**Donate Blood** is a web-based application designed to simplify and digitalize the process of **blood donation and searching**.  
It bridges the gap between **donors**, **patients**, and **hospitals** — enabling life-saving connections in emergencies.

> 💬 *“A single drop of blood can make a huge difference.”*

---

## ⚙️ Key Features

| 🌟 | Feature | Description |
|----|----------|--------------|
| 🧍‍♂️ | Donor Registration | Donors can register easily with their blood details. |
| 🧍‍♀️ | Patient Search | Patients can search verified donors by **blood group** and **location**. |
| 🛡️ | Admin Panel | Admin verifies and manages users’ information. |
| 📱 | Responsive UI | Works smoothly on mobile and desktop devices. |
| 💾 | Database Integration | Stores donor and patient details in MySQL. |
